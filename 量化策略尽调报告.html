尽调对象：东方财富 A股账户 · T+1 · 手续费约万2.5 ｜ 报告日期：2026-05-18 ｜ 性质：投资前技术与策略尽职调查（非投资建议）
⚠ 必读风险声明

本报告中的"盈利概率""收益率"等数字，绝大多数来自策略作者、自媒体或营销文案，未经独立、扣费、含滑点的严谨回测。A股短线 alpha 在 2023 年后量化普及下衰减严重，历史表现不代表未来。任何标注"胜率96%""100万变1亿"的说法在尽调中一律视为未证实营销话术，不能作为下注依据。本报告的价值在于：帮你筛掉不适配的工具、定位真正能在你环境跑起来的框架、并给出"先回测证伪、再小资金验证"的落地路径。

一、你的交易环境画像（适配基准）

券商/客户端东方财富（A股）— 决定了"实盘下单"只能走客户端GUI自动化或QMT，而非标准API
交易制度T+1（当日买入次日才能卖）+ 涨跌停 + 集合竞价 — 决定了日内回转受限，隔夜风险不可回避
手续费约万2.5（双边约万5）+ 卖出印花税千1 + 过户费 — 单次往返成本约 0.13%~0.15%
关键约束东方财富对小资金账户通常不开放官方QMT/Ptrade量化接口（多数营业部门槛≈50万资产），因此散户量化在你的环境里 = 客户端界面自动化路线
成本含义你的手续费友好，但每笔往返 ≈0.15% 是策略的"生死线"：尾盘隔日打法目标收益仅1%~3%，成本吃掉收益的 5%~15%，回测必须如实计入

尽调核心结论（先看这段）：
  • 没有以"杨永兴"命名的高星 GitHub 量化 repo。该方法是可被量化的民间短线战法，散见于通达信公式、CSDN、BigQuant 文章，需你自己复现+回测。
  • 最贴合你"东方财富实盘"的工具是 pytrader（原生 broker='eastmoney'）或 easytrader 旧版/fork——它们是"手"，不是"脑"。
  • 最强的"脑"是 微软 Qlib（AI 选因子+工业级回测），但它不连东财，需用 pytrader/easytrader 做执行桥。
  • 推荐落地架构：数据(akshare) → 信号脑(Qlib 或 自研尾盘规则) → 严谨回测(backtrader/Qlib) → 执行手(pytrader→东方财富) → 小资金验证。
  • 对杨永兴尾盘法的诚实判断：逻辑成立但 alpha 大概率已衰减，在自己跑出"扣费含滑点、含跌停无法卖出、样本外"回测前，按投机对待，不可上真金。

三、重点尽调：杨永兴"尾盘买入·隔日卖出"方法

3.1 方法背景与逻辑

杨永兴为第一、二届私募冠军，公开宣传"16个月100万→1亿"。核心打法："一夜持股法"——下午约 14:30 之后选股买入，次日 集合竞价/开盘第一时间无条件卖出，单次目标收益 1%~3%，持股时间（交易时段）不超过约2小时。

盈利原理：① 尾盘买入时当日波动基本结束，规避盘中过山车；② 利用 T+1：尾盘锁仓的强势股，次日主力常以高开/早盘拉升诱多，散户在诱多瞬间出货，赚的是"隔夜情绪惯性 + 次日早盘动量"；③ 机械纪律，不赌方向赌概率。

3.2 可量化规则（已从公开资料整理为可编程条件）

维度条件编程化判据
当日涨幅3% ~ 5%0.03 ≤ pct_chg ≤ 0.05
近期强度过去3~4日内有涨停max(pct_chg[-4:]) ≥ 0.097
流通市值排除 > 200亿float_mv < 2e10
量比> 1volume_ratio > 1
换手率5% ~ 10%0.05 ≤ turnover ≤ 0.10
分时形态全天在均价线上；14:30后创新高；回踩不破均价线分钟线：close > vwap 持续 + 尾盘新高
买入时点14:30 之后（实操常 14:50±）定时任务 14:48~14:55 扫描下单
卖出时点次日集合竞价 / 开盘瞬间，无条件09:25 集合竞价挂单 或 09:30:00 市价

注：原方法未给出止盈止损数字，硬规则是"次日开盘无条件平"。可叠加保护：开盘即走，不留盘中。

3.3 反方观点与证伪要点（按异常检测纪律 D：强制列反假设）

反假设说明 / 必须用回测证伪
数据测量口径错"涨幅3-5%、量比、换手"很多是盘中实时值，14:50 时点的值≠收盘值，回测若用收盘值=未来函数，胜率虚高。必须用14:50 时点的分钟快照回测。
幸存者/牛市偏差"100万变1亿"发生在 2006-2007 大牛市，杠杆+牛市 beta，非策略 alpha。震荡市/熊市次日低开概率大幅上升。
流动性陷阱次日"无条件卖"遇低开/一字跌停 → 卖不掉。营销回测几乎都忽略"跌停无法成交"，这是最大杀伤。
成本侵蚀目标收益仅1-3%，往返成本≈0.15%，集合竞价滑点+冲击成本可再吃 0.2-0.5%。扣费后期望可能转负。
Alpha 衰减该战法广为流传+量化普及，"尾盘强势→次日诱多"被大量资金提前博弈，2024-2026 边际效应显著递减。
营销数据不可信"胜率96%"无样本外、无扣费、无回撤；另一篇1000笔实测仅称均值约2.5%且"部分严重亏损"、未给胜率/回撤/扣费净值——等于没有有效验证。

证伪实验设计（上真金前必须做）：用 akshare 取2018-2026分钟数据 → 14:50快照选股 → 次日开盘价卖出（跌停日标记为无法卖出、按跌停价或顺延）→ 扣双边万5+印花税+0.3%滑点 → 分牛/熊/震荡三段统计胜率、盈亏比、最大回撤、样本外。三段都正期望才算通过。

3.4 在你环境的落地路线（人工 → 半自动 → 全自动）

阶段0 回测akshare + backtrader/Qlib 复现3.2规则，按3.3证伪 — 不通过则放弃
阶段1 人工用通达信/同花顺"问财"或自写 akshare 脚本，每日14:48推送候选股，手动在东方财富下单（验证真实滑点）
阶段2 半自动脚本选股 → 推送 → 你确认 → pytrader 调东方财富客户端下单
阶段3 全自动pytrader 定时14:50扫描+下单，次日09:25集合竞价挂单卖出；小资金（1-3万）跑≥2个月样本外

四、各框架详细尽调卡片

① pytrader 环境最佳匹配

定位基于 easytrader+easyquotation 的A股自动交易框架，原生 broker='eastmoney'
所需环境Windows + 东方财富PC客户端 + Python3 + TA-Lib + tushare/jqdata 数据
适配度★★★★★ 直接对接你的东方财富，含简单回测+Web看板
盈利原理自身是执行层，继承 StrategyTemplate 写策略（可装尾盘法）
盈利概率框架≈中性；取决于策略+回测纪律
风险~455 star、更新少；客户端GUI自动化随东财改版易失效，需盯维护

② easytrader 需选对版本

定位最知名的券商客户端自动下单底层库
所需环境Windows + 客户端；主线现主推同花顺客户端/miniqmt/雪球
适配度★★★★★ 东财支持在主线被弱化，需用支持东财的 fork 或经同花顺通道
盈利原理纯执行通道
盈利概率取决于策略
风险东财直连不稳；建议用 pytrader 封装，或改走"东财行情+同花顺下单"

③ Microsoft Qlib 最强信号脑

定位~4万 star 工业级AI量化平台，含因子→模型→回测全链路，A股数据齐全
所需环境Python + 较强机器，需准备A股日/分钟数据
适配度★★★★★ 研究/回测无敌，不连东方财富实盘，须自接执行桥
盈利原理ML（LightGBM/Transformer等）挖因子做多因子选股+组合优化
盈利概率研究级最高，但偏中低频组合，与"尾盘超短"风格不同；适合做选股池
风险学习曲线陡；过拟合风险高，需严格样本外

④ backtrader 验证工具

定位成熟通用回测引擎，社区大、文档全
所需环境Python；自接 akshare/tushare 数据
适配度★★★★★ 用于证伪尾盘法最合适，灵活控制成本/滑点/T+1
盈利原理不直接盈利，是"上真金前的安检门"
建议务必自定义佣金=万2.5、卖出印花税千1、滑点≥0.2%、跌停不可成交

⑤ vnpy 门槛不匹配

定位2万+ star 全栈交易平台，期货/CTA强
适配度★★★★ A股实盘走 miniqmt/QMT，多数营业部需≈50万资产，与东财散户路线冲突
结论资金达QMT门槛或做期货再考虑，否则不建议用于当前场景

⑥ abu / Rockyzsu/stock 思路参考

定位万级star的A股量化系统/30天量化教程，含打板、短线策略思路
适配度★★★★★ 基本停更，依赖旧；当策略思路库读，不直接用
价值打板/龙头战法与尾盘法逻辑相通，可借鉴选股因子

六、尽调最终判断

  • 工具层（高确定性）：你的环境最优执行方案 = pytrader 接东方财富；信号研究脑 = Qlib；回测安检 = backtrader。这三件套技术上完全可在你环境跑通。
  • 策略层（高不确定性）：杨永兴尾盘法逻辑自洽、规则可量化、与T+1天然契合，是值得投入回测的方向；但"高胜率/暴利"是营销话术，真实 alpha 是否仍存在、扣费后是否正期望，必须由你自己的严谨回测回答。
  • 大概率能盈利的策略不存在"现成答案"——开源世界给的是"脑+手+安检"，能否盈利取决于你是否用反假设纪律把这套尾盘法证伪/证真。先做W1-W3回测，不通过就换方向，这本身就是最大的风险控制。
