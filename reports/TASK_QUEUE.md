## 🚨 Goal 设置建议（给用户）

如果你要用 /goal 持续推进，**不要再设"找到最优策略"**（这是结果，物理上需要 40+ 交易日，hook 会持续 ping 不可满足）。

推荐 goal 改写：

| ❌ 不推荐 | ✅ 推荐 |
|---|---|
| "找到模拟盘最优策略" | "每周推进一个新量化领域 Gate1 验证（A-W22 → W26）+ 用户每发完反馈我立刻迭代 skill §6" |
| "Claude 持续工作直到 PASS" | "Agent A 每轮最多推一个新领域，FAIL 即停，PASS 进 paper；Agent B 等用户截图发布后反馈才动" |
| 任何"直到 / 必须达成"句式 | 任何"每轮做 X / 完成 N 个就汇报"句式（过程目标 vs 结果目标）|

具体 prompt 模板（你复制后用 `/goal` 设置）：

```
每轮推进 1 个未碰量化领域 Gate1 (A-W22 可转债→W23 期货→W24 robustness→W25 期权→W26 QDII)，
按预注册纪律 FAIL 即停 PASS 进 paper；并行接收用户发布反馈写入 xhs-data-content §6 调整下一期内容。
Claude 规划+逐 gate review，Codex MCP 执行。每轮一个 sub-agent，完成即向用户汇报，不在会话内强求最终结果。
```

这个 goal 是"过程式"的——每轮都能真实完成一步，hook 看到产物就过；不像旧 goal 那样依赖未来 40 天。
